# 🟩 Capsules vidéo — SNT · MODULE PROGRAMMER



# 📚 Récapitulatif des micro-capsules de remédiation



**Principe** : chaque capsule traite **une seule notion**, ciblée sur un **point de blocage**. ★ = priorité.




## Bloc A — Représenter une donnée
- **01f** — Les variables et l'affectation (le signe `=`) ★
- **01g** — Les types et les conversions (`input` renvoie du texte) ★
- **01h** — Les chaînes de caractères (indexation et slicing)

## Bloc B — Écrire un algorithme
- **01i** — Les conditions (`if`, `elif`, `else`) ★
- **01j** — La boucle `for` ★
- **01k** — La boucle `while` (et la boucle infinie)

## Bloc C — Traiter un jeu de données
- **01l** — Les listes (accès, parcours, opérations)
- **01m** — Les fonctions (`def`, paramètres, `return`) ★

## Bloc D — Programmer avec une intelligence artificielle
- **01n** — Ce que fait (et ne fait pas) une IA générative
- **01o** — Vérifier un code généré par une IA ★
- **01p** — Biais, coût et bon usage d'une IA
