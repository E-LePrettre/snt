# Intelligence artificielle

## <span style="color:#1565c0">Pourquoi ce module ?</span>

C'est le module où **tout converge**. Depuis le début de l'année, l'IA est revenue dans chaque thème :

- en M0, tu as vérifié du code produit par une IA — elle produit du *plausible*, pas du vrai ;
- dans *Les données*, tu as vu qu'elle apprend à partir de données, et hérite de leurs biais ;
- dans *Images*, tu as compris pourquoi elle ratait les mains ;
- dans *Réseaux sociaux*, tu as écrit un algorithme de recommandation ;
- dans *Internet*, tu as calculé ce que coûte une requête, et où tournent les modèles.

Ce module rassemble tout cela et pose enfin la question de fond : **qu'est-ce qu'apprendre, pour une machine ?**

!!! quote "Ce que ce module fait, et ne fait pas"
    Jusqu'ici, on a beaucoup dit ce qu'une IA **ne fait pas** : elle ne comprend pas, ne vérifie pas, ne veut rien.

    Ce module dit enfin ce qu'elle **fait** : apprendre à partir d'exemples, classer, prédire, générer. Et il le fait en te faisant écrire ces algorithmes toi-même — car il n'y a, là non plus, aucune magie.

!!! abstract "Objectifs du module"
    À la fin de ce module, tu sauras :

    - expliquer la différence entre **programmer une règle** et **apprendre d'exemples** ;
    - écrire toi-même un **classifieur** simple ;
    - distinguer **données d'entraînement** et **données de test**, et dire pourquoi ça compte ;
    - montrer par le code comment un **biais** des données se transmet au modèle ;
    - expliquer, sans mathématiques, comment un modèle **génère du texte** ;
    - situer les enjeux : **environnement, souveraineté, travail, création** ;
    - utiliser une IA de façon **éclairée**, dans le cadre du CRCN.

## <span style="color:#1565c0">Ce que tu réutilises</span>

Ce module ne demande **aucune notion nouvelle de programmation**. Il réinvestit tout :

| Vient de | Quoi |
| --- | --- |
| M0 bloc C | listes, fonctions, minimum/maximum |
| M0 bloc D | « plausible n'est pas vrai », les trois codes vérifiés |
| Les données bloc B–D | jeux de données, échantillon, **biais** |
| Images bloc D | génération, « mal représenté = mal produit » |
| Réseaux sociaux bloc B | recommandation, optimiser un critère |
| Internet bloc C | coût énergétique, centres de données |
